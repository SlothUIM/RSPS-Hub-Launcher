How it works

Three steps. Seriously.

1
Download the launcher

One .exe. Installs in under 30 seconds. No Visual C++ redistributable hellscape, no admin prompt, no bloatware.

2
Browse & install servers

Pick any server from the library. Hit install. RSPS Hub pulls the client, finds the right Java, configures launch args. You watch.

3
Just play

Hit Play. Client opens. Playtime clock starts. Discord RPC kicks in. You're in. That's it. That's the whole thing.

We got sick of six browser tabs, four different JARs, and zero idea how many hours we'd actually sunk into each server. Tried Alt+Tab to check our bookmarks. Forgot which Java version that server needed. Again. So we built this.
